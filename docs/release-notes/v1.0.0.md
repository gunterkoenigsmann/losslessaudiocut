losslessaudiocut 1.0: delete parts of a recording, join the rest or split
it into tracks, without ever re-encoding lossy audio. Kept audio decodes to
the same samples as the source; the only exception are the few
milliseconds right after an internal join of a lossy codec (see
[`docs/architecture.md`](https://github.com/gunterkoenigsmann/losslessaudiocut/blob/v1.0.0/docs/architecture.md),
"Join points inside a file").

## New since 0.1

- **Formats**: raw AAC (ADTS) files, fragmented MP4 (as many phones and
  live recorders write it), and ALAC cuts that are sample-exact at joins
  too. When a cut changes generated codec noise (AAC noise bands, AC-3
  dither), the export report and `lac info` say so.
- **Projects**: save and reopen the edits, tracks, tags and view as a text
  file; a recovery copy of unsaved edits survives a crash.
- **Tracks**: drag track boundaries in the waveform, reorder tracks in the
  list and the export, merge selected tracks, an End column with typed
  start and end times, double-click to zoom to a track, colour tints per
  track. Chained Ogg files offer their link boundaries, with their tags,
  as track starts.
- **Editing and playback**: right-click menus on the waveform and the track
  list, *Export selection as…*, zoom to the selection's edges
  (Ctrl+1 to Ctrl+6), play a track's beginning or end, a playback speed
  selector, a play clock you can type a time into, tooltips, and
  *File > Open recent*.
- **Control surfaces**: *Play > Control surface* lets a DAW controller in
  Mackie Control mode (X-Touch, FaderPort, ...) drive playback, the
  cursor, zoom, track splits and undo over MIDI.
- **Settings and look**: *Edit > Settings* with the detector's parameters,
  waveform options and the language; a German translation; dark mode that
  follows the system or is forced; waveform marks that scale with the
  screen's DPI.
- **Track detection** tuned on real music and spoken recordings.
- **Packages**: the Windows exe has its icon and version information, and
  the AppImage starts the command line tool too.

## Everything else

The features of 0.1 are all still there:

- **Formats**: WAV, AIFF/AIFF-C, FLAC, MP3 (bit reservoir repacked, gapless
  LAME tag), AAC and ALAC in MP4/M4A (sample-exact start and end via the
  edit list), raw AAC (ADTS), raw AC-3, Ogg Vorbis, Ogg Opus, Ogg Speex
  and Matroska/WebM Opus. Lossy audio is copied packet by packet; FLAC
  boundary frames are re-encoded losslessly.
- **GUI**: waveform with zoom down to single samples and a time ruler,
  select and delete, restore deleted parts, unlimited undo/redo, playback
  of what the export will contain, scrubbing with the right mouse button.
- **Tags**: read and written for every format (ID3v2, Vorbis comments,
  Matroska tags, RIFF INFO, AIFF text chunks, iTunes metadata); cover art
  and other frames are kept. Each track's tags can be edited in the track
  list before the export.
- **Command line tool `lac`**: `info`, `cut` (with `--delete`, `--keep`,
  `--tag`) and `detect`, which lists pauses and suggests track starts;
  manpages and bash, zsh, fish and PowerShell completions included.
- **Packages** for Windows (x64, arm64; zip and installer), macOS (Apple
  silicon and Intel; DMG), Linux (x86_64, aarch64; AppImage) and a snap.
  The program registers in "Open with" for the audio types it reads,
  without taking over the default player.

## Known limitations

- **No code signing yet**
  ([#60](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/60)):
  Windows SmartScreen and macOS Gatekeeper warn on first start. On Windows
  click *More info*, then *Run anyway*; on macOS right-click the app and
  choose *Open*, or run
  `xattr -dr com.apple.quarantine /Applications/losslessaudiocut.app`.
- **The AppImage needs Ubuntu 24.04 or newer** (glibc 2.39), and the DMG
  the macOS version of the build runner or newer
  ([#61](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/61)).
  On older Linux systems use the snap.
- **E-AC-3** (Dolby Digital Plus) is not supported yet
  ([#81](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/81));
  AC-3 cuts are frame-granular (32 ms at 48 kHz).
- **HE-AAC** (SBR/PS) in MP4 is not tested yet
  ([#74](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/74)).
- **MP3**: if the source's first or last frame lands at a join, the encoder
  delay or padding it holds becomes audible
  ([#11](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/11)).
- **Video** tracks are dropped; only the first audio track is cut.
