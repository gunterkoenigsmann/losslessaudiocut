losslessaudiocut 1.2: **`pip install losslessaudiocut`**. The command line
tool `lac` and a Python API now come as a Python package for Linux, macOS
and Windows, with nothing else to install. That makes lossless cutting
available wherever Python is, including AI assistants that install Python
packages but not programs.

## New since 1.1

- **Python package** on PyPI (`docs/python.md`):
  ```python
  import losslessaudiocut as lac
  lac.cut("talk.mp3", "short.mp3", delete=["0..12.5", "29:00.."])
  pauses = lac.detect("talk.mp3").pauses
  lac.cut("talk.mp3", "tight.mp3", delete=[p.range for p in pauses])
  ```
  `info`, `cut`, `detect` and `decode`, plus the `lac` command
  (`python -m losslessaudiocut` works too). Wheels for CPython 3.10 and
  newer on Linux (x86_64, aarch64), macOS (Apple silicon, Intel) and
  Windows (x64, arm64).
- The wheels bring their own minimal FFmpeg (audio decoders only). Each
  new FFmpeg point release is tested and published as a package update
  within a week: `pip install -U losslessaudiocut`.
- **Video preview** drawn with OpenGL, and with Metal on macOS, falling
  back to bitmaps where neither works.
- **Minimap**: dragging beside the frame zooms to the dragged range.
- **Windows**: the GUI no longer opens an empty console window next to
  itself.

## Known limitations

- No source package on PyPI: platforms without a wheel (e.g. musl Linux,
  32-bit systems) cannot `pip install` it.
- The Python package has no video preview; videos are cut as in the GUI.
- As in 1.1: players that ignore MP4 edit lists show up to one group of
  pictures more at the start of an exported video; subtitle tracks and
  further audio or video tracks are not kept.
