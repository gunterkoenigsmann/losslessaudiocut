The first release of losslessaudiocut: delete parts of a recording, join
the rest or split it into tracks, without ever re-encoding lossy audio. Kept
audio decodes to the same samples as the source; the only exception are the
few milliseconds right after an internal join of a lossy codec (see
[`docs/architecture.md`](https://github.com/gunterkoenigsmann/losslessaudiocut/blob/v0.1.0/docs/architecture.md),
"Join points inside a file").

## Highlights

- **Formats**: WAV, AIFF/AIFF-C, FLAC, MP3 (bit reservoir repacked,
  gapless LAME tag), AAC and ALAC in MP4/M4A (sample-exact start and end
  via the edit list), Ogg Vorbis, Ogg Opus, Ogg Speex and Matroska/WebM Opus. Lossy audio is
  copied packet by packet; FLAC boundary frames are re-encoded losslessly.
- **GUI**: waveform with zoom down to single samples and a time ruler,
  select and delete, restore deleted parts, unlimited undo/redo, playback
  of what the export will contain, scrubbing with the right mouse button,
  playback speed.
- **Tracks**: split a recording into tracks (Ctrl+K), name them, edit each
  track's tags in the track list, and export one file per track.
- **Tags**: read and written for every format (ID3v2, Vorbis comments,
  Matroska tags, RIFF INFO, AIFF text chunks, iTunes metadata); cover art and other frames are kept.
- **Command line tool `lac`**: `info`, `cut` (with `--delete`, `--keep`,
  `--tag`) and `detect`, which lists pauses and suggests track starts at
  long pauses and changes of timbre or key; manpages and bash, zsh, fish
  and PowerShell completions included.
- **Packages** for Windows (x64, arm64; zip and installer), macOS (Apple
  silicon and Intel; DMG), Linux (x86_64, aarch64; AppImage) and a snap. The
  program registers in "Open with" for the audio types it reads, without
  taking over the default player.

## Known limitations

- **No code signing yet**
  ([#60](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/60)):
  Windows SmartScreen and macOS Gatekeeper warn on first start. On Windows
  click *More info*, then *Run anyway*; on macOS right-click the app and
  choose *Open*, or run
  `xattr -dr com.apple.quarantine /Applications/losslessaudiocut.app`.
- **The AppImage needs Ubuntu 24.04 or newer** (glibc 2.39), and the DMG
  the macOS version of the build runner or newer
  ([#61](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/61)).
  On older Linux systems use the snap.
- **Packaging gaps**
  ([#62](https://github.com/gunterkoenigsmann/losslessaudiocut/issues/62)):
  `losslessaudiocut.exe` has no embedded icon, and the AppImage only starts
  the GUI (`--appimage-extract` gives access to `lac`).
- **Raw AAC** (ADTS, `.aac`) is not supported yet; AAC in MP4/M4A is.
  AAC bands coded with perceptual noise substitution decode to different
  (equally loud) noise after a cut in ffmpeg-based players, since their
  noise generator runs from the start of the stream.
